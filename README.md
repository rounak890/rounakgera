# Rounak Gera Portfolio

A single-page personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons. Content is maintained as typed files in `content/`.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Checks and production

```bash
npm run lint
npm run typecheck
npm run build
npm start
```

## Deploy to Vercel

Import this repository in Vercel or run `npx vercel`. The site uses standard Next.js output. Update canonical and sitemap URLs in `app/layout.tsx`, `app/robots.ts`, and `app/sitemap.ts` when a custom domain is available.

## Update content

Edit the matching TypeScript files in `content/`. Resume PDF is in `public/rounak-gera-resume.pdf`.
